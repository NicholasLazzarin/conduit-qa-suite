# Conduit QA Suite

End-to-end test suite built with Playwright and TypeScript, testing the [RealWorld](https://github.com/realworld-apps/realworld) app (a Medium clone) running locally.

This is a learning and portfolio project, built step by step. The app under test is not mine; the tests, fixtures and project structure are.

## What is covered so far

- Sign up through the UI
- Login through the UI, with the user created via API beforehand
- A reusable `newUser` fixture that creates a unique user through the API, so tests do not depend on each other

## Stack

- Playwright + TypeScript
- App under test: [realworld-django-ninja](https://github.com/c4ffein/realworld-django-ninja) backend (Django Ninja + PostgreSQL) and its React frontend, run locally with Docker

## How to run

1. Start the app under test (in the realworld-django-ninja folder):
```
   docker compose up -d
   make front-run-react
```
   The API runs at `http://localhost:8000` and the frontend at `http://localhost:4100`.

2. In this repo:
```
   npm install
   npx playwright install --with-deps
   npx playwright test
```

3. Open the report:
```
   npx playwright show-report
```

## Known limitations

- The GitHub Actions workflow is still the default generated by Playwright and fails, because it expects the app to be running. Fixing it is part of the CI step above.
- Tests are only run against Chromium during development.
